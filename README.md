# Digital Marketing Monthly Revenue Predictor

A machine-learning project and Streamlit web application for estimating the **monthly campaign-attributed revenue** generated by a digital marketing campaign. The application accepts campaign planning information and returns a predicted revenue value in Indian rupees (INR).

The project includes the source dataset, a documented modelling notebook, the saved trained model, the feature contract used by the web app, and a small data-validation script.

## Project objective

Digital marketing teams need a practical way to estimate the likely revenue from a campaign before it is launched. This project builds a regression model that predicts `Monthly_Revenue_Generated` from campaign channel, audience segment, spend, engagement, conversion, and campaign-duration information.

The predictor is intended to support planning and comparison of campaign scenarios. It is an estimate based on the historical/training data, not a guarantee of future revenue.

## Application features

- A clear Streamlit interface for entering campaign details
- Revenue prediction shown in INR
- Input controls limited to values observed in the training data
- Selectable campaign channels and target segments
- A saved, reusable preprocessing-and-regression pipeline
- Model and input-metadata checks with helpful errors if a required file is missing

## Installation and local setup

Open PowerShell in this project folder, then run the following commands.

### Option A: Quick setup

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

### Option B: Recommended virtual-environment setup

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

After the second command, Streamlit will display a local address in the terminal, usually `http://localhost:8501`. Open that address in a browser if it does not open automatically.

> On Windows, prefer `py -m streamlit run app.py` (or `python -m streamlit run app.py` in an active virtual environment) instead of `streamlit run app.py`. This avoids the common “streamlit is not recognized” PATH error.

## How to use the app

1. Start the application using one of the commands above.
2. Choose a **Campaign channel** and **Target segment**.
3. Enter the campaign’s numerical planning values.
4. Click the prediction control in the app to view the estimated monthly revenue.
5. Compare different realistic campaign scenarios by adjusting the inputs.

All monetary values are displayed in Indian rupees. Predictions should be interpreted only within the input ranges represented by the training data.

## Model inputs

The model uses nine features. `Campaign_ID` is excluded because it is an identifier, and `Monthly_Revenue_Generated` is the prediction target.

| Feature | Type | Description |
| --- | --- | --- |
| `Campaign_Channel` | Categorical | Primary channel used for the campaign. |
| `Target_Segment` | Categorical | Customer group targeted by the campaign. |
| `Ad_Spend` | Numeric | Campaign advertising spend in INR. |
| `Impressions` | Numeric | Number of times campaign content was shown. |
| `Clicks` | Numeric | Number of campaign clicks. |
| `Conversion_Rate` | Numeric | Conversion rate as a percentage. |
| `Average_Order_Value` | Numeric | Average order value in INR. |
| `Campaign_Duration_Days` | Numeric | Campaign duration in days. |
| `Email_Open_Rate` | Numeric | Email open rate as a percentage. |

### Allowed categorical values

- Campaign channel: `Affiliate`, `Display`, `Email`, `Search`, `Social Media`
- Target segment: `Existing Customers`, `High Value`, `New Customers`, `Price Sensitive`, `Small Business`

The app reads the permitted categories and numeric ranges from `feature_metadata.json`, keeping the interface aligned with the trained model.

## Modelling approach

The notebook follows a reproducible regression workflow:

1. Load and inspect the dataset.
2. Check missing values, duplicates, identifier uniqueness, category consistency, and logical rules.
3. Define feature roles and prevent target leakage.
4. Split the data into training and test sets.
5. Perform exploratory analysis, including distributions, correlations, category comparisons, and linearity checks.
6. Assess multicollinearity and regression assumptions.
7. Fit a preprocessing and linear-regression pipeline.
8. Evaluate predictions on both training and test data using standard regression metrics.
9. Interpret coefficients and business implications.
10. Save, reload, and verify the fitted pipeline as `model.pkl`.
11. Create `feature_metadata.json` for safe, consistent Streamlit inputs.

Categorical fields are encoded within the pipeline, while numeric fields are passed through as model features. Keeping preprocessing and regression together in one saved pipeline ensures that the app transforms new inputs exactly as the model expects.

## Retraining the model

The delivered app runs from the included `model.pkl` and `feature_metadata.json`; no retraining is required. To recreate them after changing the data or model:

1. Install the packages from `requirements.txt`.
2. Open and run every cell in `model_training.ipynb` from top to bottom.
3. Confirm that the notebook generates or updates `model.pkl` and `feature_metadata.json` in this folder.
4. Restart the Streamlit app.

Keep the generated files in the same folder as `app.py`.

## Data validation

Run the validation script before retraining if you want to confirm the source data’s structure and basic quality checks:

```powershell
py verify_data.py
```

The script reports dataset shape, columns, data types, missing values, duplicate rows, category values, numeric summaries, unique campaign IDs, and the logical check that clicks do not exceed impressions.

## Troubleshooting

### `streamlit` is not recognized

Install dependencies, then run Streamlit through Python:

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

### `py` or `python` is not recognized

Install Python from [python.org](https://www.python.org/downloads/) and select **Add Python to PATH** during installation. Close and reopen PowerShell afterwards.

### `ModuleNotFoundError`

Packages were installed in a different Python environment. Activate the virtual environment, if used, and run:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

### Missing `model.pkl` or `feature_metadata.json`

Restore the missing file from the project folder, or run `model_training.ipynb` from beginning to end to recreate both files.

### The app does not open in a browser

Copy the `Local URL` printed in the terminal, typically `http://localhost:8501`, and paste it into your browser.

## Limitations and responsible use

- The model learns from the supplied historical dataset; its predictions may not generalize to campaigns or market conditions that differ substantially.
- The model should not be used for high-stakes financial commitments without human review and additional validation.
- Inputs outside the observed training ranges can produce less reliable estimates. The app therefore restricts inputs to the recorded ranges.
- A predicted value reflects association patterns in the data, not proof that changing one input will cause a particular revenue result.
